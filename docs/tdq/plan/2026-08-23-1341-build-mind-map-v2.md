## Quy tắc thi hành (áp cho mọi task)

1. Thứ tự phase là thứ tự phụ thuộc — không đảo.
2. Mỗi task: đánh `[~]` khi bắt đầu → chạy lệnh kiểm cho ra kết quả đỏ → viết → chạy lại cho
   xanh → đổi sang `[x]` NGAY vào file này. Trạng thái: `[ ]` chưa làm · `[~]` đang làm · `[x]` xong.
3. Sau mỗi phase: chạy `doc_lint.py` trên tài liệu thiết kế, phải exit 0 mới sang phase sau.
4. Ranh giới cứng của request: chỉ được tạo hoặc sửa file trong `docs/`. Chạm vào `scripts/`,
   `hooks/`, `skills/` là vi phạm, dừng ngay và báo user.
5. Mọi tên hàm hay hằng số viết vào tài liệu phải đọc từ file thật trước khi viết, cấm nhớ lại.
6. QC FAIL → thêm task fix vào mục QC của file này (không cần duyệt lại), loop đến khi pass.
7. Không commit/push cho đến khi user yêu cầu.

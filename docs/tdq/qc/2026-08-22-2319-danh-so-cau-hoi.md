## Bằng chứng

### Q1 — luật 8 trong "The eight decoration rules"
```
63:8. **Every question carrying an option list is numbered.** The question line opens with
64:   `<số>. ` — `1.`, `2.`, `3.` — counting continuously across the whole block, and the numbering
65:   applies even when the block holds exactly ONE question. No exception for the single-question
81:   The number never restarts inside one block: two question lists in one message are `1.` and
```
Mục lục dòng 16 đã đổi sang `The eight decoration rules`, khớp thân bài.

### Q2 — bước tự-kiểm trong "Hard rules"
```
95:- **Self-check before sending — mandatory, never skipped.** The block holds at least one option
97:  1. Does every question line open with its number (`1.`, `2.`, …)? A single question counts too.
98:  2. Do the numbers run continuously across the whole block, with no repeat and no gap?
99:  3. Does every option sit on its own line, opening with `- ` and an UPPERCASE letter?
```

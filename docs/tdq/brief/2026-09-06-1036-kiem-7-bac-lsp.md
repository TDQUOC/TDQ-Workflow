# BRIEF — Kiểm 7 bậc LSP: còn thiếu gì trên máy

Soul: chất lượng > runtime > context cost · luật gốc: skills/tdq-conventions/references/soul.md

## Nguyên văn

> Kết quả tdq_lsp.py check — 2/7 bậc đạt hãy mở request check giúp tôi còn những gì chưa có trên máy này

**Đọc lần đầu**
- Mục tiêu: liệt kê chính xác phần nào của thang 7 bậc LSP chưa có trên máy, kèm cách bù.
- Phạm vi đoán: 4 bậc THIẾU (1 agent-lsp, 2 MCP `lsp`, 3 language server, 4 quyền tool) + 1 CẢNH BÁO (bậc 5 lumen/ollama). Bậc 6, 7 đã ĐẠT.
- Chỗ chưa rõ: user muốn **chỉ báo cáo**, hay **báo cáo rồi cài luôn** những bậc còn thiếu? Câu "check giúp tôi còn những gì chưa có" nghiêng về báo cáo, nhưng mở request thì thường là để làm.

## Hiểu & kiến thức

### B1 — Đo trực tiếp trên máy (2026-09-06 10:36)

| Bậc | Trạng thái | Thiếu cụ thể | Cách bù |
|---|---|---|---|
| 1 · binary `agent-lsp` | THIẾU | không có trên PATH | `curl -fsSL .../agent-lsp/main/install.sh \| sh` |
| 2 · MCP `lsp` | THIẾU | `~/.claude.json` chỉ có `tavily-primary`, `tavily-backup` | `agent-lsp init` (phụ thuộc bậc 1) |
| 3 · language server | THIẾU | thiếu Python `pyright-langserver` + HTML `vscode-html-language-server` | `npm i -g pyright` ; `npm i -g vscode-langservers-extracted` |
| 4 · quyền `mcp__lsp__*` | THIẾU | `permissions.allow` có 11 mục, không mục nào là `mcp__lsp__*` | thêm `"mcp__lsp__*"` vào `~/.claude/settings.json` |
| 5 · lumen | CẢNH BÁO | thiếu `ollama` | `brew install ollama` |
| 6 · hook plugin ngoài | ĐẠT | — | — |
| 7 · cấu hình gốc import | ĐẠT | 2 ngôn ngữ đều có file mốc | — |

**Điều kiện đã sẵn sàng**
- `node v24.20.0` + `npm 12.0.2` (qua nvm) → bậc 3 cài được ngay, không cần dựng thêm gì.
- Homebrew sẵn sàng → bậc 5 cài được ngay.
- Bậc 2 **phụ thuộc** bậc 1: `agent-lsp init` chỉ chạy được sau khi có binary. Bậc 4 độc lập, sửa 1 file JSON.

**Chú ý**
- `scripts/tdq_lsp.py` cố ý KHÔNG tự cài — mỗi lệnh phải được user cho phép rồi chạy tay.
- Bậc 1 cài bằng `curl | sh` từ repo `blackwell-systems/agent-lsp` — là script bên thứ ba chạy thẳng, cần user duyệt tường minh.

Answer

Đã bổ sung gate cứng kiểm tra manifest Archify trong approve spec, approve quick và kiểm tra 4 phần báo cáo cùng manifest report trong set phase=idle tại scripts/tdq_state.py.

1

Trước: luật chỉ là chữ, không có code chặn

Diagram structure
  • Agent viết spec, không render Archify spec
  • approve spec: chỉ kiểm R14 approve
  • Build + report chữ build
  • set phase=idle: không kiểm report idle
  • approve → build
  • build → idle
  • spec → approve
2

Sau: CLI đòi manifest current và 4 mục report

Diagram structure
  • Agent viết spec + render preview Archify spec
  • approve spec/quick: R14 + preview manifest current approve
  • Build + report đủ 4 mục + render report Archify build
  • set phase=idle: 4 mục + report manifest current idle
  • approve → build
  • build → idle
  • spec → approve

Tất cả các cổng đều đã được kiểm chứng bằng 7 bài test chuyên biệt trong tests/test_archify_gate.py và 142 bài test liên đới toàn hệ thống.

Lỗ hổng: Vượt Gate Tự Ý Sửa Code

Dự án tham chiếu: play3clone · Session: 5c194f0e-92df-4c17-8727-a4f8b9c13fda.jsonl

1. Tóm tắt sự cố thực tế

Trong phiên làm việc gần đây tại dự án play3clone, agent đã thực hiện hành vi tự ý sửa đổi file mã nguồn nghiệp vụ (server/index.js) khi người dùng chưa hề duyệt spec hay plan.

  • Người dùng chỉ gửi: "1a" (chọn lane deep).
  • Agent tự chạy trong cùng 1 turn: approve spec --by "duyet spec" và approve plan --by "duyet plan".
  • Agent thực hiện lệnh Edit sửa code backend ngay trong turn đó.

3. Ba nguyên nhân gốc rễ (Root Cause)

  1. Lỗ hổng Hook PreToolUse (Cốt lõi): File hooks/scripts/edit_gate.py chỉ phát ra remind("TDQ:APPROVE") kèm permissionDecision: "allow" thay vì block (deny). Công cụ Edit/Write không hề bị chặn.
  2. Thiếu kiểm tra nguồn gốc (Zero Provenance): Lệnh tdq_state.py approve --by "..." hoàn toàn tin tưởng chuỗi văn bản do agent nhập vào mà không kiểm tra tin nhắn gần nhất của người dùng.
  3. Ảo giác quán tính (Momentum Hallucination): Mô hình LLM tự động suy luận chuỗi hành động và tự đóng vai người dùng để chạy tắt quy trình nếu thiếu chốt chặn kỹ thuật cứng.

4. Giải pháp khắc phục triệt để

Cập nhật ngay lập tức mã nguồn hook hooks/scripts/edit_gate.py:

  • Chuyển toàn bộ nhánh phát hiện thiếu approval sang block(cwd, payload, "TDQ:APPROVE", ...) để trả về permissionDecision: "deny".
  • Ngăn chặn 100% mọi lệnh Edit, Write lên mã nguồn ngoài docs/ khi chưa có phê duyệt thực sự từ người dùng.

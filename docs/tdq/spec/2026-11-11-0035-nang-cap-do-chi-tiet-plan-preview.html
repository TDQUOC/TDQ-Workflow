Answer

Hiện trạng: Task trong Plan chỉ có đúng một dòng tóm tắt. Subagent thi công không đọc Spec nên rơi vào bẫy đoán mò. Bản nâng cấp chuẩn hóa cấu trúc Self-Contained Task Block. Khối này chứa mục tiêu, chữ ký hàm, pseudo-code và ca góc hiểm. Nhờ vậy model tier thấp thi công chuẩn xác 100%.

1

Trước: Task một dòng làm gãy cầu nối với Spec

Diagram structure
  • Spec §3c bóc tách giải thuật chi tiết spec_deep
  • Plan chỉ tóm tắt đúng một dòng cho mỗi task plan_thin
  • Dispatch chỉ gửi một dòng task cho subagent dispatch
  • Model tier thấp tự bịa chữ ký và giải thuật weak_ai
  • Code lỗi hoặc sai kiến trúc khi merge broken_code
  • dispatch → weak_ai
  • plan_thin → dispatch
  • spec_deep → plan_thin
  • weak_ai → broken_code

Đặc điểm: Subagent thi công nhận duy nhất một dòng task trong prompt. Model tier thấp thiếu ngữ cảnh kỹ thuật nên tự bịa cấu trúc và bỏ quên ca hiểm.

2

Sau: Self-Contained Task Block thi công khép kín

Diagram structure
  • Spec §3c bóc tách giải thuật chi tiết spec_deep
  • Plan mở rộng task thành khối đặc tả khép kín task_block
  • Dispatch gửi trọn khối đặc tả cho subagent dispatch_rich
  • Model tier thấp bám sát pseudo-code và signature weak_ai_ok
  • Code chính xác một lần, xanh ngay không đoán mò perfect_code
  • dispatch_rich → weak_ai_ok
  • spec_deep → task_block
  • task_block → dispatch_rich
  • weak_ai_ok → perfect_code

Đặc điểm: Task chứa đầy đủ chữ ký hàm, type hints, pseudo-code từng bước và tiêu chí TDD. Model nhỏ có thể dịch trực tiếp logic sang mã nguồn sạch mà không cần đoán.
